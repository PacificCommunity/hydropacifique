<b>Vous pouvez choisir un ou plusieurs fichiers à importer en cliquant sur le bouton de sélection de fichiers.</b>
<br>
La station doit être enregistrée dans l'application.<br>
Menu : <i>Module / Stations de mesure</i>
<br>
Le type de chronique doit être enregistré dans l'application.<br>
Menu : <i>Paramétrage / Chroniques</i>
<br>--<br>
<b>Format CSV</b><br>
Nom de fichier : <code>codeStation_initialChronique</code><br>
(ex : <b><code>5700503100_CI.csv</code></b>)
<br>--<br>
<b>Colonnes</b>
<br>
Le séparateur de colonne peut être <code>;</code> ou <code>,</code> (reconnu automatiquement).
<br>
Les données doivent se présenter en 3 colonnes (la 3<sup>e</sup> colonne est facultative) :
<br>
<b>date_heure</b> : dd/mm/yyyy hh:mm:ss (ex : <code>13/01/2018 10:53:24</code>)
<br>
<b>valeur</b> : nombre décimal (<code>.</code> ou <code>,</code>)
<br>
<b>qualite</b> : code qualité (peut être nulle ou vide)<br>
Le code qualité doit être enregistré dans l'application.<br>
Menu : <i>Paramétrage / Codes qualités</i>.
<br><br>
Les en-têtes de colonnes sont ignorées : elles ne sont ni demandées ni proscrites.
<br>--<br>
