<b>You can select one or more files to import by clicking the file selection button.</b>
<br>
The station must be registered in the application.<br>
Menu: <i>Module / Measurement Stations</i>
<br>
The time series type must be registered in the application.<br>
Menu: <i>Settings / Time Series</i>
<br>--<br>
<b>CSV Format</b><br>
File name: <code>stationCode_seriesInitials</code><br>
(e.g.: <b><code>5700503100_CI.csv</code></b>)
<br>--<br>
<b>Columns</b>
<br>
The column separator can be <code>;</code> or <code>,</code> (automatically recognized).
<br>
Data must be presented in 3 columns (the 3<sup>rd</sup> column is optional):
<br>
<b>date_time</b>: dd/mm/yyyy hh:mm:ss (e.g.: <code>13/01/2018 10:53:24</code>)
<br>
<b>value</b>: decimal number (<code>.</code> or <code>,</code>)
<br>
<b>quality</b>: quality code (can be null or empty)<br>
The quality code must be registered in the application.<br>
Menu: <i>Settings / Quality Codes</i>.
<br><br>
Column headers are ignored: they are neither required nor forbidden.
<br>--<br>
